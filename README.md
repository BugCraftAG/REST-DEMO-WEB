# Wirtshaus Rebenhof – Demo-Website

Eine Website für ein **fiktives** steirisches Wirtshaus. Gebaut als Beispielprojekt für mein Portfolio.

**Live ansehen:** https://DEIN-USERNAME.github.io/demo-restaurant/

## Was die Seite kann

- Zeigt live an, ob das Lokal gerade geöffnet ist (österreichische Zeit)
- Mittagsmenü mit Wochentagen, öffnet automatisch beim heutigen Tag
- Speisekarte, Öffnungszeiten mit Hervorhebung von heute, Anfahrt
- Funktioniert auf Handy, Tablet und Desktop
- Reine HTML, CSS und JavaScript, ohne Frameworks, lädt schnell

## Aufbau

```
demo-restaurant/
├── index.html      Inhalt der Seite
├── css/style.css   Design (Farben oben in :root)
├── js/main.js      Öffnungszeiten, Mittagsmenü, Handy-Menü
└── images/         eigene Fotos
```
